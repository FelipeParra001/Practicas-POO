PROJECT TITLE: Condominius - Gestion de condominios
PURPOSE OF PROJECT: Proyecto academico POO. Plataforma que centraliza varios condominios: unidades (apartamentos y casas), propietarios con varias unidades, residentes, administradores, vigilantes, control de visitantes, vehiculos autorizados, pagos de administracion, reservas de zonas comunes sin cruces y paquetes.
VERSION or DATE: 2026
HOW TO START THIS PROJECT: Ejecutar el metodo main de la clase Main
AUTHORS: Andres Felipe Parra Castellanos - 1152626
USER INSTRUCTIONS: Primero registrar un condominio y sus unidades (pestaña Condominios), luego las personas (pestaña Personas). Despues se pueden registrar visitantes, vehiculos, pagos, reservas y paquetes en sus pestañas. Los resultados salen en el area de texto de abajo.
