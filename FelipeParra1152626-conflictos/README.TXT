PROJECT TITLE: Conflictos belicos
PURPOSE OF PROJECT: Registrar conflictos (territoriales, religiosos,
  economicos y raciales), grupos armados con su lider politico y sus
  divisiones, y ver un reporte con muertos, heridos y bajas.
VERSION or DATE: 1.0
HOW TO START THIS PROJECT: Entrar al paquete Principal, clic derecho en
  Main -> void main(String[] args)
AUTHORS: Andres Felipe Parra Castellanos (1152626)
USER INSTRUCTIONS:
  Paquetes (3 capas):
  - modelo: Conflicto y sus subclases, Pais, GrupoArmado, Division,
    LiderPolitico, JefeMilitar, Traficante, TipoArma, Suministra,
    OrganizacionMediadora, Dialogo, Intervencion, Fecha y GestorConflictos.
  - vista: JFConflictos (solo componentes graficos).
  - controlador: ControlConflictos (eventos y validaciones).
  - Principal: Main (crea el modelo, la vista y el controlador).
